# ai-fashion-stylist
AI Fashion Design Generator Many students want to explore fashion design but lack artistic or technical skills. Traditional tools are expensive and time-consuming. A generative AI solution that can create clothing designs from text prompts and suggest similar affordable products online would make fashion design more accessible and fun.
# 👗 AI Fashion Stylist

An intelligent and interactive **AI Fashion Stylist** web application that provides personalized outfit recommendations based on a user's **age, gender, occasion, budget, body type, skin tone, preferred style, and preferred colors**.

The application combines personalized styling recommendations with an interactive fashion assistant to help users discover suitable outfits for different occasions and moods.

## ✨ Features

### 🤖 Personalized AI Outfit Recommendations

Users can enter their personal preferences and generate customized fashion recommendations based on:

* 👤 Name
* 🎂 Age
* ⚧ Gender
* 🎉 Occasion
* 💰 Budget
* 👗 Body Type
* 🎨 Skin Tone
* 💎 Preferred Style
* 🌈 Preferred Color

The system generates recommendations covering:

* 👚 Outfit
* 💍 Accessories
* 👠 Footwear
* 🎨 Color suggestions
* ✨ Styling suggestions

### 🎯 Occasion-Based Styling

Users can explore recommendations for different occasions, including:

* Casual
* Formal
* Wedding
* College / Campus
* Date Night
* Interview
* Other lifestyle occasions

### 🔎 Outfit & Color Filters

The Outfits section allows users to filter recommendations based on:

* Occasion
* Color preference
* Fashion style

This makes it easier to discover relevant outfit combinations.

### 💬 AI Fashion Chat Assistant – "Stella"

The application includes an interactive fashion assistant named **Stella**.

Users can ask Stella for fashion advice, outfit suggestions, and styling ideas.

Example topics include:

* 🎯 Interview Outfit
* 💍 Wedding Guest
* 🔥 Fashion Trends
* 🎨 Color Combinations
* ♻️ Sustainable Fashion
* 🏖️ Beach Outfit
* 🪔 Diwali Outfit
* 👗 Saree Styling
* 💼 Formal Accessories
* 🌧️ Monsoon Fashion

### 😊 Mood-Based Fashion Suggestions

Users can select their current mood and receive styling suggestions based on it.

Supported moods demonstrated in the application include:

* 💪 Confident
* 🌸 Romantic
* ❤️ Loving
* 🔥 Energetic
* 😍 Excited
* 🎉 Celebratory

For example, a confident mood can suggest **bold colors, structured silhouettes, and statement accessories**, while a romantic mood can suggest **soft colors, floral patterns, and delicate jewellery**.

### 👩‍🎨 Stylist Personas

The application provides different stylist personas to create a more personalized fashion consultation experience.

The demonstrated interface includes the **Stella – Classic** stylist persona.

### ❤️ Wishlist

Users can save their favorite outfit recommendations to a **Wishlist** for later reference.

### 📄 Download Recommendation as PDF

Generated recommendations can be exported using the **Download PDF** option, allowing users to keep or share their personalized styling recommendations.

### 🔍 Fashion Search

A search interface allows users to search for:

> "outfits, styles..."

This provides a convenient way to explore fashion-related recommendations.

### 🌙 Modern User Interface

The application features a modern fashion-focused interface with:

* Dark theme
* Gradient styling
* Responsive cards
* Interactive buttons
* Navigation menu
* Clean form layout
* Personalized recommendation panels
* Chat-style interface
